Tiny Room Keys

PC Volume Live

Each box holds a tiny room. Each room hides a way out.

A parcel arrives with no return address: a wooden box holding a perfect miniature room. Turn each 3D diorama to see every wall, open briefcases, drawers and vents, use tools in the right place and set the code locks. Somewhere in each room is a brass key that opens the way out, and a note from Edith, the miniaturist who built them. Eight rooms, from the night vault to the gold vault and finally Edith's own workshop, are memories of her forty years working nights at the Crown and Thimble Bank, and the last key is the one she kept for you.
